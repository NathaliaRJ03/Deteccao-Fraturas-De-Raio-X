# 🩻 Detecção de Fraturas em Radiografias

> Projeto de Inteligência Artificial e Visão Computacional desenvolvido individualmente para detecção de possíveis fraturas em imagens de raio-X.

## 💡 Sobre o projeto

**E se uma IA pudesse ajudar a identificar possíveis fraturas em uma radiografia?**

A partir dessa ideia, desenvolvi **sozinha, do início ao fim**, um projeto de Visão Computacional utilizando aproximadamente **3.000 imagens de radiografias**.

O modelo foi treinado para identificar regiões com possíveis fraturas e realizar a detecção diretamente nas imagens.

## 🤖 Modelo

Utilizei o **YOLOv10**, através da biblioteca **Ultralytics**, para realizar o treinamento e a detecção.

Durante os testes, analisei diferentes níveis de confiança e trabalhei na identificação de falsas detecções e nas limitações relacionadas à quantidade de dados disponíveis.

## 🛠️ Tecnologias

- Python
- YOLOv10
- Ultralytics
- PyTorch
- OpenCV


## 📊 Dataset

Aproximadamente **3.000 imagens de raio-X**, com regiões de interesse anotadas para o treinamento do modelo.
